How it decides: USB

On this board every pin of the left-edge ports connects to the battery, and every pin of the far-end port drives its own LED. A lit LED means that pin reaches the other end of the cable. A cable gets Keep when every pin its two plugs can carry lights, nothing else lights, and the shield is connected.

  • The best a cable can do is set by its weaker plug. A Micro-B 2.0 or USB-A 2.0 plug tops out at USB 2.0, so a fully wired USB 2.0 cable with one of those plugs gets Keep.
  • Put USB-A 3.x plugs in the blue Type-A 3.0 port. The Type-A 2.0 port has no SuperSpeed contacts.
  • Treedix doesn't document which LEDs the Micro-B 3.0 and USB-B 3.0 SuperSpeed pins use. The checker expects TX2± and RX1±. If your board uses others, any four lit SuperSpeed LEDs still count.
  • LEDs can't show wire thickness (charging speed), swapped wires, or signal quality. Chips in Lightning plugs and e-marked USB-C cables can change the pattern.

How it decides: HDMI

Every HDMI connector size carries the same 19 signals plus the metal shell, and the board gives each one an LED. So the best possible result is the same for every cable: all 20 LEDs lit. Plug size only changes which port you use.
